# OpenNELOCR

一个针对4399训练的 OCR（光学字符识别）模型库，基于 ONNX 格式实现。

## 文件组成

本项目包含以下 OCR 相关文件：

- `common.onnx`: 一个预训练的 ONNX 格式 OCR 模型
- `charset.json`: 字符集定义文件
